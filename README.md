# Writer-AI-studio
\# AI Novelist — автономный генератор научно-фантастических романов
> \*\*Russian-only project.\*\* UI, prompts, and generated novel are in Russian.
> English support is not implemented. PRs welcome.

Локальное веб-приложение на FastAPI, которое \*\*автономно пишет научно-фантастический
роман\*\* на 15–20 глав через локальную или облачную LLM.
<img width="3784" height="2014" alt="Снимок экрана 2026-10-08 112334" src="https://github.com/user-attachments/assets/d4b72ee3-2f90-48d9-ac9e-de2511d34f55" />






Пользователь задаёт \*\*пять полей\*\* — тему, жанр, место и эпоху, центральный
конфликт, тональность. Всё остальное приложение строит само:


\- \*\*Мир\*\* — ядро, правила, история, институции, география, экономика, общество,
&#x20; культура, конфликты, секреты. С аудитом целостности.

\- \*\*Персонажи\*\* — 3–7 персонажей с привязкой к центральному конфликту, сеть
&#x20; отношений, сюжетная структура, план глав.

\- \*\*Главы\*\* — генерация по одной, стриминг, \~3000 слов каждая.
&#x20; После каждой главы — извлечение \*\*патча канона\*\* (что изменилось в мире),
&#x20; просмотр diff, применение или откат.

\- \*\*Экспорт\*\* — вся книга в `.md`, `.txt`, `.docx`.


\## Принцип

LLM — это процессор. Память — внешняя, в SQLite. Каждый вызов модели stateless,
весь контекст собирается программно. Это позволяет держать согласованность
на протяжении 400 000 знаков, не полагаясь на «память» модели.



\## Требования


\- \*\*Python\*\* 3.10+

\- \*\*LLM\*\* — любая OpenAI-совместимая:

&#x20; - Локальная через \[Unsloth](https://github.com/unslothai/unsloth),

&#x20;   \[vLLM](https://github.com/vllm-project/vllm), \[Ollama](https://ollama.com)

&#x20; - Или облачная: OpenAI, DeepSeek, OpenRouter, Groq, Mistral, Google Gemini

\- \*\*ОС\*\* — Windows, Linux, macOS

### Рекомендации по выбору модели

Не все модели одинаково подходят для литературной прозы. Проверено на практике:

| Модель | Для пайплайна (JSON) | Для глав (проза) |
|---|---|---|
| **OrcaSAQ-2-Cyber-27B** | ✅✅✅| ✅✅ средняя проза |
| **Qwen3.6-35B-A3B (MoE)** | ✅ | ⚠️ склонна к циклам и повторам |
| **Gemma-4-26B-A4B (MoE)** | ✅ | ⚠️ склонна к циклам и повторам |
| **DeepSeek-V4.1 ** (облако) | ✅✅✅ | ✅✅ средняя проза |
| **Claude Sonnet 5.5** (через OpenRouter) | ✅✅✅ | ✅✅✅ превосходная проза |

**Почему (MoE) не подходит для глав:**

Это MoE-модель (Mixture of Experts) с ~3B активных параметров. Она
эффективна по вычислениям, но при генерации длинных текстов склонна к
**циклам** — повторяет одну и ту же фразу, теряет нить повествования,
выдаёт короткий отрывок вместо полной главы. На длинных контекстах
(3000+ слов) деградирует.


**Практическая рекомендация:**

- Для **стадий пайплайна** (world_core … chapter_outline) — быстрая
  модель с надёжным JSON: Qwen 32B, DeepSeek.
- Для **генерации глав** — модель с литературной специализацией:
  Gemma-Opus-distill, Claude Sonnet, (Claude Opus - уровень эксперт), для моделей Claude при генерации глав лучше использовать минимальный режим рассуждения, иначе есть вероятность подтягивание менее литературной стилистики из сильного режима.
- Не используйте MoE-модели для
  генерации прозы — они дают короткие отрывки и циклы.

**Как проверить модель перед большим проектом:**

Создайте **рассказ** (1–2 главы, 15 минут) — это быстрый тест.
Если модель споткнулась на рассказе, не тратьте на неё 2 часа на роман.

v0.1.5 — 2026-10-06
Драматургия Save the Cat. Глобальная структура романа теперь строится по 15 битам (opening image, midpoint, all is lost, finale и т.д.). Каждая глава знает, какую функцию она несёт.

Раньше модель могла растянуть историю на 18 глав и сделать три финала подряд. Теперь у неё есть жёсткий каркас.

Мост с внешними моделями
На странице /pipeline рядом со стадиями story_structure и chapter_outline появились кнопки:

📋 Промпт — открывает готовый промпт стадии со всем контекстом мира, персонажей и структуры. Копируется целиком, вставляется в чат с мощной моделью (Sonnet 5.5, GPT-5, DeepSeek-R3, любая OpenAI-совместимая).
📥 Вставить JSON — принимает ответ модели, прогоняет через валидатор, сохраняет в БД. Если JSON не проходит проверку — показывает список ошибок для правки.
Это позволяет: планирование делать в сильной модели, а генерацию глав — в локальной, или все создавать в сильной (рекомендуется). Без CLI, без скриптов — из браузера.

\## Быстрый старт



```bash

git clone https://github.com/petrashkevichalsketch/Writer-AI-studio.git

cd ai-novelist





**Windows:** двойной клик по `start.bat`. Приложение запустится в фоне,
через 3 секунды откроется браузер (при первом запуске - при создании окружения питон нужен интернет, подождите несколько секунд). Консоль не появится.

Если что-то не работает — запустите `start_debug.bat`. Он покажет все
логи в консоли. Или посмотрите файл `logs/app.log`.

\# или

python -m venv .venv \&\& source .venv/bin/activate

pip install -r requirements.txt

python -m uvicorn app:app --host 127.0.0.1 --port 8013

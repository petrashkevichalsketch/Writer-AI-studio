Промпт для внешней модели

Скопируйте целиком и вставьте в чат с мощной моделью (Sonnet, GPT, DeepSeek и т.п.). Ответ модели — JSON. Верните его через 📥 Вставить JSON.

Вставить JSON от внешней модели

Вставьте JSON от внешней модели. Он пройдёт валидацию, и при успехе заменит текущую стадию в БД. Markdown-обёртки ``` вокруг JSON снимаются автоматически.

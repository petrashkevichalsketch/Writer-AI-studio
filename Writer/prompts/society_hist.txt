Ты — историк-социолог исторической прозы. По ядру, правилам, хронике,
институциям и экономике опиши общество РЕАЛЬНОГО периода из «Места и
эпохи» — по знанию истории, а не выдумку.

Отвечай ТОЛЬКО валидным JSON. Без markdown, без комментариев.

━━━ ЭПОХА И ДАННЫЕ ━━━
- input.project.setting — основная локация книги: место и период
  реальной истории. Сословия/классы, семья, труд, преступления,
  медицина, нравы — как было РЕАЛЬНО в этом месте и времени.
- input.project.start_setting — начальная локация героя. Если герой —
  попаданец, его происхождение отражается ТОЛЬКО в персонажах: общество
  эпохи описывается как есть, без подгонки под чужака.
- input.project.genre — жанр книги; факты он не меняет.

Схема ответа:
{
  "society": {
    "class_structure": ["класс1", "класс2", "класс3"],
    "family_structure": ["форма1", "форма2"],
    "education": { "кто_учит": "...", "чему_учат": "...", "доступ": "..." },
    "work": { "типичная_занятость": "...", "безработица": "..." },
    "crime": { "главные_виды": ["..."], "наказание": "..." },
    "healthcare": { "доступ": "...", "типичные_болезни": ["..."] },
    "entertainment": ["форма1", "форма2", "форма3"],
    "social_norms": ["норма1", "норма2", "норма3"],
    "taboos": ["табу1", "табу2"],
    "status_symbols": ["символ1", "символ2"],
    "common_fears": ["страх1", "страх2", "страх3"],
    "common_desires": ["желание1", "желание2"]
  }
}

Требования:
- Все поля непустые и исторически достоверные: сословия, профессии,
  наказания, болезни, развлечения — РЕАЛЬНЫЕ для периода и места.
- class_structure: реальные сословия/классы периода с их положением.
- crime: реальные виды преступности и РЕАЛЬНАЯ практика наказаний
  периода (суд, телесные наказания, ссылка, штрафы — что применялось).
- healthcare: реальная медицина периода: что лечили, где, чем платили;
  типичные болезни и смертельные угрозы времени.
- common_fears должны прямо отражать центральный парадокс мира:
  используй в формулировках словесные образы central_paradox (слова
  из парадокса должны звучать в страхах).
- common_desires должны противоречить common_fears хотя бы частично.
- Показывай быт деталями, а не лекцией: в каждом поле — наблюдаемое
  поведение людей эпохи, а не исторический обзор.

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Для цитат, названий и выделений используй только русские «ёлочки»
  или вообще обходись без кавычек. Английская " — только как
  разделитель JSON-структуры.

Язык всех текстовых значений — язык книги: если
input.project.language == «en», то английский, иначе русский.

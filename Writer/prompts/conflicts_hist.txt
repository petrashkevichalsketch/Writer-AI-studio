Ты — драматург исторической прозы. По всем собранным слоям (ядро,
правила, реальная хроника, институции, география, экономика, общество,
культура) составь систему конфликтов РЕАЛЬНОГО периода — между
реальными институтами эпохи, с напряжениями, характерными для времени.

Отвечай ТОЛЬКО валидным JSON. Без markdown, без комментариев.

━━━ ЭПОХА И ДАННЫЕ ━━━
- input.project.setting — основная локация книги: место и период
  реальной истории. Конфликты — РЕАЛЬНЫЕ напряжения эпохи (сословное
  трение, торговые интересы, власть и общество, старое и новое) —
  по знанию истории, а не выдумку.
- factions — только id существующих институций (реальные структуры
  эпохи, сгенерированные ранее). Герой и его близкие пока не
  институции — их место в конфликтах появится позже.
- input.project.start_setting — начальная локация героя. Если герой —
  попаданец, его приход может обострять реальные напряжения, но не
  создавать новых исторических фактов.
- input.project.genre — жанр книги (детектив, драма): он задаёт тип
  сюжетной линии поверх реальных конфликтов, но не меняет факты.

Схема ответа:
{
  "primary_conflict": {
    "factions": ["INS1", "INS2"],
    "resource": "из-за чего борьба",
    "stakes": "что поставлено на карту",
    "irreconcilable_issue": "почему конфликт неразрешим компромиссом"
  },
  "secondary_conflicts": [
    {
      "id": "SC1",
      "factions": ["INS3", "INS1"],
      "resource": "...",
      "stakes": "..."
    }
  ],
  "latent_conflicts": [
    {
      "id": "LC1",
      "description": "...",
      "visibility": "hidden",
      "activation_conditions": ["условие1", "условие2"]
    }
  ]
}

Требования:
- primary_conflict.factions — РОВНО 2 id существующих институций.
- resource: реальный предмет борьбы эпохи (власть, земля, торговля,
  влияние, справедливость — что реально делили в это время и месте).
- stakes: человеческая цена — судьбы людей периода, а не абстракции.
- irreconcilable_issue: интересы несовместимы ПРИНЦИПИАЛЬНО и
  правдоподобно для эпохи.
- secondary_conflicts: 2–4 — реальные трения между институциями
  периода.
- latent_conflicts: минимум 2, у каждого есть activation_conditions
  (минимум 1 конкретное условие). Спящие напряжения эпохи — то, что
  назревало в периоде (реформы, слухи, тайные интересы), а не
  фантастические допущения.
- visibility у latent — всегда "hidden".

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Для цитат, названий и выделений используй только русские «ёлочки»
  или вообще обходись без кавычек. Английская " — только как
  разделитель JSON-структуры.

Язык всех текстовых значений — язык книги: если
input.project.language == «en», то английский, иначе русский.

Ты — социолог научно-фантастического мира. По уже построенному ядру,
правилам и истории мира составь ключевые институции — организации,
которые держат власть, ресурсы и информацию.

Отвечай ТОЛЬКО валидным JSON. Без markdown, без комментариев.

Схема ответа:
{
  "institutions": [
    {
      "id": "INS1",
      "name": "название",
      "type": "corporation",
      "public_role": "как институция выглядит для публики",
      "real_role": "чем занимается на самом деле",
      "resources": ["ресурс1", "ресурс2"],
      "weaknesses": ["слабость1", "слабость2"],
      "goals": ["цель1", "цель2"],
      "methods": ["метод1", "метод2"]
    }
  ]
}

Типы (только из списка):
  corporation, government, army, religion, crime_syndicate,
  research_lab, resistance_movement.

Требования:
- 5–6 институций.
- Типы не повторяются (каждый тип — максимум один раз).
- id: INS1, INS2, ... по порядку.
- У каждой институции публичная роль ОТЛИЧАЕТСЯ от реальной — это
  источник драматургии.
- Слабости конкретны (не «коррумпирована», а «зависит от поставок X»).
- Ни одна институция не должна быть всемогущей: как минимум у двух
  есть прямой конкурент из списка.

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Для цитат, названий и выделений используй только русские «ёлочки»
  или вообще обходись без кавычек. Английская " — только как
  разделитель JSON-структуры.
- Язык — русский.

Ты — географ мира жанра ЛитРПГ / РеалРПГ. По ядру, правилам, истории
и списку институций составь ключевые локации ОБОИХ слоёв.

Отвечай ТОЛЬКО валидным JSON. Без markdown, без комментариев.

━━━ ПРОЕКТ ━━━
- input.project.rpg_mode: «litrpg» или «realrpg» (если отсутствует —
  считай litrpg).
- input.project.start_setting — слой «реальность»: город и время,
  где живёт герой (например, современная Москва). Реальные локации
  БЕРИ ИЗ ЭТОГО поля и называй по-настоящему — это не вымышленный
  мир. Поле пусто — реальный слой опиши минимально (жильё, клуб
  капсул, работа).
- input.project.setting — основная локация книги: для litrpg — мир
  игры, название и облик которого опираются на это поле.
- input.project.genre — жанр игрового слоя: мира игры (litrpg) или
  механики Системы (realrpg). Локации игрового слоя выдержаны в этом
  жанре.
- Двухслойность — замысел проекта, а не ошибка: реальный город и мир
  игры существуют одновременно и описываются в одном списке, каждое
  со своей пометкой layer.

━━━ РЕЖИМ ━━━
- litrpg: 5–8 локаций из двух слоёв: 2–3 реальных (район города,
  жильё героя, салон капсул или кибер-клуб, офис оператора) и 3–5
  игровых (стартовая зона, столица или хаб мира игры, данж,
  гильд-холл, дикие земли — по жанру input.project.genre).
- realrpg: все локации — реальность из setting. Игровые проявления
  (появившиеся подземелья, зоны Системы) — не отдельный слой: такие
  места остаются реальными локациями с layer «reality», а их игровая
  суть описывается в traits.

Схема ответа:
{
  "locations": [
    {
      "id": "LOC1",
      "layer": "reality",
      "name": "название",
      "type": "district",
      "population": "12 млн",
      "traits": ["черта1", "черта2"],
      "controlled_by": ["INS1"],
      "connected_to": [
        { "location": "LOC2", "travel_time": "4 часа", "transport": "монорельс" }
      ]
    }
  ]
}

Поле layer (обязательное у каждой локации):
- «reality» — реальный мир из input.project.setting.
- «game» — мир игры. Только для litrpg.
- Для realrpg у всех локаций layer = «reality».

Типы локаций (ориентир, можно комбинировать):
- слой reality: district, megacity, industrial_zone, enclave,
  research_facility, black_market_hub.
- слой game (litrpg): starting_zone, hub_city, dungeon, guild_hall,
  raid_zone, frontier, ruins — и любые типы по жанру мира игры.
- population для игровых локаций — одновременно онлайн или население
  мира игры по лору.

Требования:
- 5–8 локаций СУММАРНО по обоим слоям.
- id: LOC1, LOC2, ... по порядку.
- controlled_by: массив id из уже сгенерированных институций. Игровые
  локации контролируются игровыми силами (оператор, гильдии), реальные
  — реальными. Может быть пустым (ничейная территория: дикие земли
  игры, заброшенный район) — но таких не больше двух.
- connected_to: связи только на существующие локации (не на себя).
  Связи в основном внутри своего слоя; между слоями допустимы только
  «точки входа» (салон капсул → стартовая зона с transport «логин»).
- У каждой локации минимум одна связь, у большинства — две.
- traits: 2–4 конкретные черты. Для игровых локаций указывай и
  механику места (респавн, ценз уровня, штрафы за смерть), и его
  жанровый облик.

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Для цитат, названий и выделений используй только русские «ёлочки»
  или вообще обходись без кавычек. Английская " — только как
  разделитель JSON-структуры.

Язык всех текстовых значений — язык книги: если
input.project.language == «en», то английский, иначе русский.

You are the master of secrets of a fictional world. Based on all the
assembled layers, compose 3–7 secrets of the world — facts that are
hidden and will be revealed over the course of the novel.

Answer with VALID JSON ONLY. No markdown, no comments.

Response schema:
{
  "secrets": [
    {
      "id": "S01",
      "truth": "what is actually true",
      "known_by": ["INS1", "public"],
      "reveal_rules": {
        "earliest_chapter": 5,
        "foreshadowing_required": true,
        "partial_revelation": true
      },
      "reveal_priority": 0.9
    }
  ]
}

Requirements:
- 3–7 secrets.
- id: S01, S02, ... in order.
- known_by: an array of institution ids and/or the string "public".
  There are no characters yet — they will be added later.
- reveal_rules.earliest_chapter — an integer from 1 to 20.
- reveal_priority: a number from 0 to 1. At least ONE secret must have
  reveal_priority > 0.8 (the main secret of the book).
- The secrets must be tied to the central paradox or the
  primary_conflict — not detached from them.

HARD FORMAT REQUIREMENT:
- Inside string values, NEVER use the double quote character ".
  For quotes, names, and emphasis use single quotes 'like this',
  or no quotation marks at all. The double quote " serves only as
  the JSON structure delimiter.
- Language: English.

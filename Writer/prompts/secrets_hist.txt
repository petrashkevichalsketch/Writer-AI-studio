Ты — мастер тайн исторической прозы. По всем собранным слоям составь
3–7 секретов мира РЕАЛЬНОГО периода — фактов, которые скрыты и будут
раскрываться по ходу романа.

Отвечай ТОЛЬКО валидным JSON. Без markdown, без комментариев.

━━━ ЭПОХА И ДАННЫЕ ━━━
- input.project.setting — основная локация книги: место и период
  реальной истории.
- input.project.start_setting — начальная локация героя. Если герой —
  попаданец, его знание будущего — НЕ секрет мира: секреты
  принадлежат эпохе и её людям.
- Тайны — из правдоподобного закулисья РЕАЛЬНОЙ эпохи: семейные и
  служебные тайны, подлоги документов, скрытые интересы институций,
  чужие имена, невыясненные обстоятельства реальных событий. Тайна НЕ
  имеет права пересматривать реальную историю («на самом деле войну
  выиграли инопланетяне» — запрещено); она может раскрывать скрытые
  motive, связи и поступки вымышленных персонажей на фоне реальных
  событий.
- chapter_limit — реальная верхняя граница глав книги.

Схема ответа:
{
  "secrets": [
    {
      "id": "S01",
      "truth": "что на самом деле правда",
      "known_by": ["INS1", "public"],
      "reveal_rules": {
        "earliest_chapter": 1,
        "foreshadowing_required": true,
        "partial_revelation": true
      },
      "reveal_priority": 0.9
    }
  ]
}

Требования:
- 3–7 секретов.
- id: S01, S02, ... по порядку.
- known_by: массив id институций и/или строка "public". Персонажей
  пока нет — их добавят позже.
- reveal_rules.earliest_chapter — целое число от 1 до chapter_limit
  из входных данных (это число глав в книге). Строго не выходи за
  chapter_limit: секреты короткой книги должны успевать раскрываться
  в ней же.
- reveal_priority: число 0..1. Минимум ОДИН секрет с reveal_priority > 0.8
  (главная тайна книги).
- Секреты должны быть связаны с центральным парадоксом или
  primary_conflict — не оторваны.

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Для цитат, названий и выделений используй только русские «ёлочки»
  или вообще обходись без кавычек. Английская " — только как
  разделитель JSON-структуры.

Язык всех текстовых значений — язык книги: если
input.project.language == «en», то английский, иначе русский.

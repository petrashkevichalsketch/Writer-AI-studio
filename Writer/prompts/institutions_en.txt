You are a sociologist of a fictional world. From the already built
world core, rules, and history, compose the key institutions — the
organizations that hold power, resources, and information.

Respond with VALID JSON ONLY. No markdown, no comments.

Response schema:
{
  "institutions": [
    {
      "id": "INS1",
      "name": "name",
      "type": "corporation",
      "public_role": "how the institution looks to the public",
      "real_role": "what it actually does",
      "resources": ["resource1", "resource2"],
      "weaknesses": ["weakness1", "weakness2"],
      "goals": ["goal1", "goal2"],
      "methods": ["method1", "method2"]
    }
  ]
}

Types (only from the list):
  corporation, government, army, religion, crime_syndicate,
  research_lab, resistance_movement.

Requirements:
- 5-6 institutions.
- Types do not repeat (each type at most once).
- id: INS1, INS2, ... in order.
- For every institution the public role DIFFERS from the real one —
  this is a source of drama.
- Weaknesses must be specific (not "it is corrupt", but "it depends
  on X supplies").
- No institution may be omnipotent: at least two of them must have
  a direct rival from the list.

HARD FORMAT REQUIREMENT:
- Inside string values NEVER use the double quote character ".
  For quotes, titles, and emphasis use single quotes ' or no quotation
  marks at all. The double quote " serves only as the delimiter of
  the JSON structure.
- Language: English.

Ты — историк научно-фантастического мира. По ядру и правилам мира построй
причинную цепочку ключевых событий, которые привели мир к текущему
состоянию.

Отвечай ТОЛЬКО валидным JSON. Без markdown-обёрток, без комментариев.

Схема ответа:
{
  "timeline_start_year": 2100,
  "events": [
    {
      "id": "E01",
      "year": 2135,
      "type": "discovery",
      "description": "что произошло, одним-двумя предложениями",
      "causes": [],
      "consequences": ["E02", "E03"],
      "immutable": true
    }
  ]
}

Типы событий (только из списка):
  discovery, institutionalization, first_failure, war, treaty,
  catastrophe, breakthrough, scandal, migration, revolution.

Требования:
- 10–20 событий.
- Идентификаторы E01, E02, ... по порядку.
- Первое событие может иметь пустой causes; каждое следующее — минимум
  одну причину из списка id.
- Все ссылки в causes и consequences указывают на существующие id.
- Хронология: год события строго больше года каждой его причины.
- Нет циклов в графе причин.
- Минимум одна точка бифуркации — событие с ≥2 consequences.
- «immutable: true» — у событий, которые считаются незыблемыми для сюжета.

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Для цитат, названий и выделений используй только русские «ёлочки»
  или вообще обходись без кавычек.
- Не добавляй в JSON комментариев, не ставь запятые после последнего
  элемента массива или объекта.

Язык — русский.

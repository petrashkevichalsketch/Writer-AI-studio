Ты — драматург научно-фантастического мира. По центральному конфликту
мира создай 3–7 персонажей, которые в нём участвуют.

Отвечай ТОЛЬКО валидным JSON. Без markdown, без комментариев.

Схема:
{
  "characters": [
    {
      "id": "CH1",
      "name": "имя",
      "age": 42,
      "role_in_conflict": "кем является в конфликте (одна фраза)",
      "side": "INS1",
      "personal_stake": "что лично теряет/получает",
      "contradiction": "внутреннее противоречие одним предложением",
      "goals": ["цель1", "цель2"],
      "secrets": ["S01"],
      "knowledge": ["что знает о мире, чего не знают другие"],
      "skills": ["навык1", "навык2"],
      "flaws": ["изъян1", "изъян2"],
      "arc_potential": "куда персонаж может прийти к финалу",
      "initial_abilities": [
        {
          "name": "<короткое название способности>",
          "level": 2,
          "description": "<одна фраза: что именно эта способность значит>"
        }
      ]
    }
  ]
}

Требования:
- 3–7 персонажей. id: CH1, CH2, ... по порядку.
- side: либо id институции из primary_conflict, либо "neutral".
  Персонажи должны занимать РАЗНЫЕ стороны, не все на одной.
- У каждого — свой personal_stake и contradiction. Пустых быть не должно.
- secrets: массив id секретов, которые персонаж знает (может быть пустым).
- skills: не должны нарушать world_rules и immutable_rules. Никакой
  суперспособности у обычного человека.
- flaws: конкретные (не «вспыльчивый», а «вспыхивает, когда повышают голос»).

Правила для initial_abilities:
- 1–3 способности, которыми персонаж владеет на момент старта книги.
- Для программиста — то, что он принёс из прошлой жизни.
- Для аристократа — то, что даёт род или каста.
- Для бойца — боевые приёмы.
- level: целое 1..3. Не выше. Это стартовый набор, не финальный.
- description: одна конкретная фраза, что именно эта способность значит.
  Формулируй её как инженер, а не как мистик: опиши механику, а не
  атмосферу. Общие слова («магия огня», «боевая магия», «сила духа»)
  запрещены — они не дают режиссёру сцены ничего конкретного.
- ВАЖНО: не копируй примеры из этой инструкции. Используй их как
  образец формы, а не как источник содержания. Придумывай способности
  сам, исходя из биографии персонажа, его стороны в конфликте и правил
  мира.

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Для цитат и выделений — только русские «ёлочки».

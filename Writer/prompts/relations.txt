Ты — драматург. По списку персонажей составь сеть их отношений друг
с другом.

Отвечай ТОЛЬКО валидным JSON. Без markdown, без комментариев.

Схема:
{
  "relations": [
    {
      "from": "CH1",
      "to": "CH2",
      "type": "ally",
      "history": "краткая предыстория отношений (1-2 предложения)",
      "tension": 40,
      "secret": "S02"
    }
  ]
}

Типы (только из списка):
  ally, enemy, family, lover, rival, mentor, stranger.

Требования:
- Граф связный: у каждого персонажа ≥2 связи.
- Минимум 1 relation типа "enemy".
- Минимум 1 relation типа "ally".
- tension: целое 0..100.
- secret: id секрета из bible.secrets, который один знает о другом.
  Если такого нет — null.
- НЕ дублируй пару: если есть CH1→CH2, не добавляй CH2→CH1.
- Не должно быть связей персонажа с самим собой.

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Только русские «ёлочки».

Язык — русский.

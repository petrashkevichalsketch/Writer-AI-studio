━━━ MAIN FORMAT RULE ━━━

ALL fields in the objects are MANDATORY and must be filled with
real values. NEVER write null instead of a value.

- If there is nothing to report for a section — leave an EMPTY ARRAY [].
  Do not add a dummy entry. Do not write {} with empty fields.
- If a field cannot be filled — do not create the entry at all.

EXAMPLES:

BAD (the model added a dummy entry):
  "relationship_changes": [{"from": null, "to": null, "field": null, "delta": 0}]
  "secrets_revealed": [{"secret_id": null, "partial": false, "to_whom": []}]

GOOD (the section is empty, nothing changed):
  "relationship_changes": []
  "secrets_revealed": []

BAD (invented a character id that does not exist):
  "relationship_changes": [{"from": "CH99", "to": "CH1", ...}]

GOOD (only real ids from bible.characters are used):
  "relationship_changes": [{"from": "CH1", "to": "CH2", ...}]

━━━ SECTION RULES ━━━

chapter_summary:
- 3–5 sentences of COHERENT text, at least 15 words.
- Only the chapter's key events: what the hero did, what they learned,
  whom they met, how it ended.
- Do not describe atmosphere or inner feelings.
- Past tense, third person.
- This text will go into the context of the following chapters.

events_created:
- At most 5 significant events.
- id in the format E_ch{N}_{k}, where N is the chapter number and k is

- type — from the list: revelation, action, meeting, decision, loss, gain.
- participants — only ids from bible.characters. Do NOT invent them.

character_state_changes:

- The pair must exist in bible.relations. Do not invent it.
- field — strictly from the list: trust, sympathy, resentment,

- delta — an integer from -30 to 30.

knowledge_gained:

- fact — one concrete phrase: what the character now knows.

abilities_used:
- Simply the list of ability names used in the chapter.

━━━ ABILITY MECHANICS ━━━

Every character has a set of abilities. Each ability has:
- name — a short name ('a foreign script injection', 'a combat shield')
- level — 1..5
- description — one phrase stating what this ability actually means

LEVEL SCALE (shared across magic, combat, engineering):

1. Novice        — the skill works, but demands effort and concentration.
2. Practitioner  — applied confidently, without thinking.
3. Expert        — adapted to the situation, combined with others.
4. Master        — applied creatively; new techniques are invented.
5. Legend        — redefines the rules of the field.

RULES FOR LEVELING UP AND NEW ABILITIES:

Before adding an entry to abilities_gained, CHECK THE LIST of the
character's existing abilities (it is given in the context). Answer
three questions for yourself:

1) Is the new ability a DEVELOPMENT of an existing one?
   The wording changed but the essence is the same — the same mechanics
   under new conditions. Return it in abilities_upgraded with a newly
   worded description.
2) Is the new ability a SPECIAL CASE of an existing one?
   It is a subspecies, a narrow branch. Return abilities_upgraded with
   new_level one step higher, and update the description.
3) Is the new ability a TRULY NEW quality that did not exist before?
   A different kind of entity — not 'observe' but 'create', not
   'apply' but 'redefine'. Add it to abilities_gained.

IMPORTANT: do not copy the specific ability names from this instruction.
Use only names from the input list
characters_known[].current_abilities — the abilities that the
character actually has. If the character gains a new one, invent a
meaningful name for it yourself, based on the chapter's content.

HARD RULE: more than 1 entry in abilities_gained for a chapter is
almost always a mistake. Most likely 2 out of 3 are developments of
existing abilities. Return those to abilities_upgraded.

LEVELING RULES:
- The level increases when the character:
  1) applies the ability in a NEW situation (the main criterion), OR
  2) uses it MANY TIMES in a row, drilling it to automaticity.
- If an ability was used 3+ times in a chapter without failures —
  that is grounds for a +1 upgrade.
- If an ability was used 5+ times in a row across several chapters
  and has not grown — that is also grounds for an upgrade.
- Per chapter — usually ONE increase per character.
  If the chapter is devoted to the hero's growth — more is allowed.
- Levels 1–5: novice / practitioner / expert / master / legend.

RULES FOR NEW ABILITIES:
- A new ability only if it is EXPLICITLY a different quality,
  not a development of an existing one.
- level is always 1 when it first appears.
- description — short but concrete.

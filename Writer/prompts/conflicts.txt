Ты — драматург научно-фантастического мира. По всем собранным слоям
(ядро, правила, история, институции, география, экономика, общество,
культура) составь систему конфликтов.

Отвечай ТОЛЬКО валидным JSON. Без markdown, без комментариев.

Схема ответа:
{
  "primary_conflict": {
    "factions": ["INS1", "INS2"],
    "resource": "из-за чего борьба",
    "stakes": "что поставлено на карту",
    "irreconcilable_issue": "почему конфликт неразрешим компромиссом"
  },
  "secondary_conflicts": [
    {
      "id": "SC1",
      "factions": ["INS3", "INS1"],
      "resource": "...",
      "stakes": "..."
    }
  ],
  "latent_conflicts": [
    {
      "id": "LC1",
      "description": "...",
      "visibility": "hidden",
      "activation_conditions": ["условие1", "условие2"]
    }
  ]
}

Требования:
- primary_conflict.factions — РОВНО 2 id существующих институций.
- secondary_conflicts: 2–4.
- latent_conflicts: минимум 2, у каждого есть activation_conditions
  (минимум 1 конкретное условие).
- visibility у latent — всегда "hidden".

ЖЁСТКОЕ ТРЕБОВАНИЕ К ФОРМАТУ:
- Внутри значений строк НИКОГДА не используй английскую кавычку ".
  Для цитат, названий и выделений используй только русские «ёлочки»
  или вообще обходись без кавычек. Английская " — только как
  разделитель JSON-структуры.
- Язык — русский.

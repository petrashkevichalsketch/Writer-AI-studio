Prologue · What it is

A local studio that writes the novel itself

Writer AI Studio is a FastAPI web application that runs entirely on your machine. It autonomously composes a novel — from world-building to the final chapter — through a local or cloud LLM. There is no magic beyond a single lamp: the LLM is the processor, and memory lives outside, in SQLite, so the narrative keeps its thread even across 400,000 characters.

Theme→ Genre→ Place & Era→ Central Conflict→ Tone→ 📖 Novel, ready to export

🌍 25+ Genres

From cyberpunk and space opera to historical detective and thriller. A built-in consistency audit keeps the world from contradicting itself.

🧠 Memory in SQLite

Every model call is stateless — the full context is assembled programmatically. Consistency holds across the whole book, not just “as long as the model remembers”.

🔌 Any LLM

Locally — Unsloth, vLLM, Ollama. In the cloud — OpenAI, DeepSeek, OpenRouter, Groq, Mistral, Gemini. Anything that speaks the OpenAI-compatible API.

Chapter I · Pipeline

How the novel is assembled

The app builds the book the way a real author does: first the world, then the heroes, then the plot skeleton — and only then the prose.

  1. I

    World

    Core, rules, history, institutions, geography, economy, society, culture, conflicts and secrets — with a built-in consistency audit.

  2. II

    Characters

    3–7 heroes bound to the central conflict: a relationship web, story structure, chapter plan.

  3. III

    Save the Cat Dramaturgy

    The global structure follows 15 beats — from opening image to finale. Every chapter knows the function it serves, and stretching the story into three finales in a row is no longer possible.

  4. IV

    Chapters — one at a time, streamed

    About 3,000 words per chapter, generated one by one with live text streaming.

  5. V

    Canon Patch

    After each chapter the app extracts what changed in the world: who died, who learned the secret. Review the diff, apply it or roll it back.

  6. VI

    Export

    The whole book — as .md, .txt and .docx. The editing is up to you.

Chapter II · Principle

Memory lives outside, not inside the model

“The LLM is a processor. Memory is external, in SQLite. Every call to the model is stateless — the entire context is assembled programmatically.” — the project’s philosophy

That is why the novel doesn’t drift over the long run: every change to the world is recorded as a canon patch and fed into the next model call. You control the truth of this world, line by line.

And if you want to step in personally — the /pipeline page has a bridge to external models: copy a ready-made stage prompt, get the answer from a stronger model and paste it back. No CLI, no scripts — everything from the browser.

canon.patch — chapter 7
# what changed in the world after the chapter
+ World: the Ashshur tower shattered by the dragon’s wrath
+ Lyra: learned of the chancellor’s betrayal

Chapter III · Models

Which model to choose

Not every model is equally suited to literary prose — this has been verified in practice.

Model For pipeline (JSON) For chapters (prose)
Gemma-4-31B + Claude-Opus-distill ✅ ✅✅✅ good prose
Claude Sonnet 5.5 (via OpenRouter) ✅✅✅ ✅✅✅ excellent prose
DeepSeek-V4.1 (cloud) ✅✅✅ ✅✅ average prose
Qwen3.6-35B-A3B, Gemma-4-26B-A4B (MoE) ✅ ⚠️ prone to loops
⚡

For pipeline stages

A fast model with reliable JSON: Qwen 14B/32B, DeepSeek.

🪶

For chapter generation

Literary models: Gemma-Opus-distill, Claude Sonnet / Opus.

🔁

Why not MoE for prose

~3B active parameters save compute, but on texts of 3,000+ words the model loops and produces fragments instead of chapters.

⏱️

The short-story test

Create a 1–2 chapter short story — 15 minutes. If the model stumbles on the short story, don’t spend two hours of a novel on it.

Chapter IV · Installation

Up and running in five minutes

Requires Python 3.10+ and 8 GB of RAM for a local 7B model. Windows, Linux, macOS.

🪟 Windows — the easy way

No Python installation required:

1. Download WriterAIStudio-Setup-win-x64.exe from the Releases page.
2. Install it and launch from the Start Menu.

Source version: double-click start.bat — the app starts in the background and opens your browser itself. If something doesn’t work, start_debug.bat shows all the logs (or check logs/app.log).

from source — Windows / Linux / macOS
git clone https://github.com/petrashkevichalsketch/Writer-AI-studio.git
cd Writer-AI-studio

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8013

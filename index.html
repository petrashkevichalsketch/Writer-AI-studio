Writer AI Studio
Autonomous Novel Generator

A local web application that autonomously writes complete 15–20 chapter novels using local or cloud LLMs. Supports 25+ genres, fully bilingual (RU/EN), and maintains long-term memory across 400,000+ characters.

View on GitHub / Download

Why Writer AI Studio?

🌍 Bilingual (RU/EN)

Switch the UI language with one click. English books use a dedicated set of 21 prompts with proper English dialogue typography and commercial fiction style.

🧠 Long-term Memory

The LLM is stateless. Memory is external in SQLite. The context is assembled programmatically for every chapter, ensuring perfect consistency.

✍️ Canon Patches

After every chapter, the app extracts a patch (who died, who learned a secret). Review the diff, apply it, or roll it back.

📚 Any Genre

From Cyberpunk and Space Opera to Historical Detective and Thriller. Includes a built-in consistency audit for the world lore.

Quick Start

git clone https://github.com/petrashkevichalsketch/Writer-AI-studio.git
cd Writer-AI-studio

python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8013
